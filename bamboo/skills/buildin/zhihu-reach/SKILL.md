# Zhihu Reach

## When to Use

Use this skill when the task needs Zhihu question, answer, article, column, zvideo links, search results, visible comments, author/profile analysis, or page metadata.

Do not use this skill for generic web search, Xiaohongshu, Bilibili, YouTube, or private account data.

## Browser-First Boundary

Use Bamboo's `browser` tool as the primary execution path when login, dynamic answer lists, comments, author pages, search results, or pages hidden behind a login wall are needed.

Do not read browser cookies, local storage, login state, account tokens, private drafts, private messages, or private API credentials directly. Login must happen only through a visible browser window opened by `browser action=open` with `headless=false`; the user completes QR/SMS/CAPTCHA manually. If Zhihu returns login walls, CAPTCHA, risk-control pages, or incomplete public HTML, use `browser action=wait_for_login` or ask for visible-browser approval instead of trying credential extraction.

State-changing actions such as like, favorite, follow, comment, answer, edit, publish, delete, vote, report, private message, or account switch require an explicit final user confirmation after showing the exact target and content.

## Browser Workflows

### Login

1. Open `https://www.zhihu.com/` or the target Zhihu URL with `browser action=open`, `headless=false`.
2. Ask the user to complete QR/SMS/CAPTCHA in the visible browser.
3. Use `browser action=wait_for_login` with a selector or URL pattern that indicates login has completed.
4. Continue in the same browser session; never copy cookies or tokens into prompts, files, or command arguments.

### Question, Answer, Article, or Zvideo

1. Use `parse` first when the user pasted Zhihu share text.
2. Open the canonical URL in the visible browser.
3. Wait for the main content area.
4. Use `browser action=extract_text` or `browser action=eval` to extract visible title, author, answer/article text, visible stats, comments, publish/update time, and links.
5. For long answer lists, sample a bounded number of visible answers and report the sample size.

### Search

1. Open a search URL generated by `search-url` or use the page search box.
2. Let the user complete login/risk-control challenges.
3. Extract visible result cards, authors, snippets, links, and stats.
4. Apply filters only through visible controls when the user asks for them.

### Author or Topic Analysis

1. Open the author/profile/topic page in the visible browser.
2. Extract visible profile fields, recent content cards, titles, dates, and public stats.
3. Sample a bounded number of visible items and summarize themes, stance, answer style, and update rhythm.
4. Clearly mark gaps when data is hidden by login, pagination, folded content, or risk control.

## Commands

```bash
python3 <skill_dir>/scripts/zhihu_cli.py parse "Zhihu share text or URL"
python3 <skill_dir>/scripts/zhihu_cli.py page "https://www.zhihu.com/question/..."
python3 <skill_dir>/scripts/zhihu_cli.py search-url "keyword"
```

Use `python` instead of `python3` only when `python3` is unavailable and `python --version` reports Python 3.

## CLI Fallback Workflow

1. Load this skill for Zhihu-specific requests.
2. Prefer browser workflows for dynamic or login-dependent tasks.
3. Use `parse` first when the user pasted Zhihu share text; return extracted URLs and detected entities.
4. Use `page` for a known public Zhihu URL to fetch and summarize public page metadata.
5. Use `search-url` when the user needs a Zhihu search link for a keyword and public search fetching is not required.
6. Keep final answers grounded in returned public URLs and command output.
7. Do not claim access to comments, logged-in answers, private drafts, follower-only content, or personalized feeds unless the browser-visible page or command result explicitly contains it.

## Failure Handling

If public pages fail, redirect to a login wall, or return risk-control content, report the status and ask for a public URL or pasted public content. Do not bypass rate limits, CAPTCHA, or login requirements.
